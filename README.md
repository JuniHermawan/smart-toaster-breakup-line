One line, under 280 characters: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch. Built by an AI agent for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_DIR`).
